# VisionInspector 开发计划

> 开发团队：用户(零基础) + AI助手
> 开发周期：不限，直到成功
> 技术栈：C++ + Qt + OpenCV + 开源库
> 原则：小步快跑，每一步都要能运行看到效果

---

## 总体路线图

```
阶段1: 环境搭建 + 项目骨架      → 能编译能运行的空壳程序
阶段2: 主界面框架               → 菜单/工具栏/停靠窗口布局
阶段3: 相机采集                 → 能接GigE相机拍照显示
阶段4: 基础检测工具             → BLOB/边缘/圆形/直线/亮度
阶段5: 流程编辑器               → 拖拽节点编排检测流程
阶段6: PLC通讯                  → Modbus控制吹气/伺服
阶段7: 数据栏 + 统计            → OK/NG统计/良率显示
阶段8: 界面DIY编辑器            → 用户自定义运行界面
阶段9: 螺纹检测                 → 牙数/烂牙/缺牙/毛刺
阶段10: 模板匹配 + 标定校准     → 定位 + 坐标转换
阶段11: 插件化重构              → 工具动态加载
阶段12: 整机联调                → PLC+伺服+相机+吹气全链路
阶段13: 多相机支持              → 1-8台即插即用
阶段14: 扩展设备类型预留        → 贴标/计数模板
```

---

## 阶段1: 环境搭建 + 项目骨架

**目标**: 搭建开发环境，创建能编译运行的Qt项目骨架

**环境准备**:
- 安装 Visual Studio 2022 Community（免费）或 MinGW
- 安装 Qt 6.x（开源版LGPL免费）
- 安装 CMake
- 下载 OpenCV 源码并编译
- 配置 vcpkg 或手动管理第三方库

**产出**:
- `CMakeLists.txt` 顶层构建文件
- `src/app/main.cpp` 程序入口
- `src/app/MainWindow.h/cpp` 主窗口（空壳）
- 能编译出一个空白的Qt窗口程序

**验证**: 运行程序，看到一个空白窗口

---

## 阶段2: 主界面框架

**目标**: 搭建类似CKVision的主界面布局

**产出**:
- 菜单栏（文件/设置/操作/视图/帮助）
- 主工具栏（新建/打开/保存/运行/停止）
- 基于Qt-Advanced-Docking的停靠窗口布局：
  - 显示区域（中心）
  - 流程栏（可停靠）
  - 工具箱（左侧可停靠）
  - 数据栏（底部可停靠）
  - 日志栏（底部可停靠）
- 状态栏

**验证**: 运行程序，看到完整的界面布局，各面板可拖拽停靠

---

## 阶段3: 相机采集

**目标**: 能连接GigE相机，实时采集和显示图像

**产出**:
- `hal/ICameraDriver.h` 相机驱动抽象接口
- `plugins/cameras/AravisCamera/` Aravis通用GigE相机插件
- 相机工具节点（采集图像、实时预览）
- 相机参数配置面板（曝光、增益、触发模式）
- 图像显示控件（缩放、拖动、适应）

**验证**: 接上GigE相机，软件中能看到实时图像

---

## 阶段4: 基础检测工具

**目标**: 实现核心检测算法

**产出**:
- `engine/ITool.h` 工具基类接口
- `engine/ToolRegistry.h/cpp` 工具注册表
- 检测工具插件：
  - BLOB分析（OpenCV connectedComponents）
  - 边缘检测（OpenCV Canny + 亚像素）
  - 圆形检测（OpenCV HoughCircle + 最小二乘拟合）
  - 直线检测（OpenCV HoughLineP + 拟合）
  - 亮度检测（OpenCV mean/meanStdDev）
- 每个工具的属性配置面板
- 检测结果在图像上可视化叠加

**验证**: 加载测试图片，运行各检测工具，看到检测结果

---

## 阶段5: 流程编辑器

**目标**: 实现可视化流程编排

**产出**:
- 基于QtNodeEditor的流程编辑器
- 工具箱面板（分类列出所有工具）
- 拖拽工具到流程画布
- 节点间数据连接
- 流程执行引擎（按顺序执行节点）
- 流程保存/加载（JSON格式）

**验证**: 拖拽几个工具组成流程，执行流程，看到数据在节点间传递

---

## 阶段6: PLC通讯

**目标**: 实现与信捷PLC的Modbus通讯

**产出**:
- `hal/IPLCDriver.h` PLC驱动抽象接口
- `plugins/plc/XinjePLC/` 信捷PLC插件（基于libmodbus）
- 通讯工具：
  - Modbus读数据
  - Modbus写数据
  - 状态输入（读IO）
  - 状态输出（写IO，控制吹气）
- PLC地址映射配置

**验证**: 软件能通过Modbus读写PLC数据，能控制输出信号

---

## 阶段7: 数据栏 + 统计

**目标**: 实现数据统计和良率显示

**产出**:
- 数据栏面板（QTableView或自定义）
- 检测项配置（名称、上下限）
- 实时统计（OK数、NG数、占比）
- 全局统计（总数、良品、不良品、重测数、良率）
- 数据记录工具（将检测结果插入数据栏）

**验证**: 运行检测流程，数据栏实时更新统计数据

## 阶段12: 整机联调

**目标**: 全链路联调

**产出**:

- 伺服位置反馈 → 相机拍照位置同步
- 转速设定
- 异常处理和日志

**验证**: 实际设备上跑通全流程

---

## 开发原则

1. **每步可运行** — 每个阶段结束时，程序必须能编译运行
2. **小步快跑** — 不要一次性写太多，写一点测一点
3. **先能用再优化** — 功能实现优先，性能优化后做
4. **用户能看懂** — 每个阶段完成后，向用户解释做了什么
5. **保留文档** — 每个阶段记录关键决策和遇到的问题
