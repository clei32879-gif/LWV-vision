# 工业AI视觉软件竞品调研报告

> 调研日期：2026-08-29 ｜ 调研目的：为 LW Vision 的 AI 功能规划提供"别人是怎么做"的参考

## 一、军哥讲视觉 / MIP工业视觉框架（"ADvision"未证实）

**身份**：CSDN博主"军哥讲视觉"（blog.csdn.net/qq_17767255，8年视觉从业）+ B站UP主（space.bilibili.com/448881795，教程《MIP框架初步使用教程》BV1AN4y1879n）。全网多渠道检索**均未找到"ADvision"这款软件**——其已发布的软件实名 **MIP工业视觉框架**（Gitee开源 + 百度网盘完整版），"ADvision"疑为抖音侧别名或记忆偏差（低可信度）。

- **定位**：Qt开发的"开放式视觉组态框架"，逻辑界面参照LabVIEW/VisionPro，组件=信号槽，带反射机制、工程保存、外部数据接口（CSDN《MIP工业视觉框--框架介绍》blog.csdn.net/qq_17767255/article/details/134602482）。
- **AI做法**：工具节点含"检测标注/分类标注/分类推理"三件套+模板匹配、阈值等传统件（details/135652568）。方法论很明确：**传统算法强特征定位矫正 → ROI裁剪(256/512) → 每区域二分类（预训练迁移学习）**，原因是大图压缩丢特征、缺陷样本难收集（details/135567267）。同时深入研究**无监督异常检测**（PaDiM路线：EfficientNet多层特征+多元高斯+马氏距离，details/134308114）和 GMM one-class（details/132761093）。2025年转向**工业检测大模型+RAG**：用OK图建向量库"引导"大模型找缺陷，宣称摆脱微调、小样本可用（details/153573561）。
- **形态/商业化**：个人开源项目+网盘分发，B站播放量仅200左右，影响力小，无定价。

## 二、深度视觉 DLCV.AI（信息可信度：高，官网+GitHub+文档站）

深度视觉（广东）人工智能研究有限公司，2024年成立，广州番禺（dlcv.com.cn）。

- **产品**：一体化"深度视觉AI平台"（AI标注+AI训练+AI测试+部署），标→训→测→部**全流程闭环**；测试平台直接输出过检率/漏检率/mAP/多硬件推理测速。
- **AI路线**：**有监督**分类/检测/实例分割+预训练模型少样本微调，"100张图训练仅需1分钟"；官网未提无监督异常检测。自研C++推理SDK（量化/混合精度，宣称提速10~100倍）。开源生态：**OpenIVS**（github.com/dl-cv/OpenIVS，240★，.NET/WPF整框架：海康相机+Halcon接口+Modbus PLC+模型推理，Apache-2.0）和 **labelme-ai**（AI辅助标注）。
- **行业**：皮革、锂电极片/密封钉、3C外观、PCB、木材、布匹等14案例。
- **形态/定价**：Win10/11桌面客户端，N卡驱动≥562（CUDA12.6）；**加密狗买断制**，"标注训练测试免费不限时试用"，无订阅。
- **话术**：免费试用、1分钟训练、万张/秒推理、低配显卡可部署、一次付费免维护。

## 三、广州视觉芯 Visioncore-Halocn21（信息可信度：中高）

广州视觉芯软件有限公司（www.sjx99.com，凡科建站），CSDN企业号显示技术栈VC++/OpenCV/神经网络。**"Visioncore-Halocn21"字样未直接检索到**，但其"AI常见问题"页明确出现 `halcon.dll 2021`——可推断其软件基于 **HALCON 21.11** 构建，版本名即"Halocn21"+日期版（如2026-8-1，推断，低可信度）。

- **定位**：视觉检测**整机/筛机**软件：电容（鼓包/偏极/字符/封口结晶）、螺丝、弹簧、密封圈、电池凹坑、瓶盖二维码、塑胶件、尺寸检测、视觉点数/点料系统，配套VC-400控制卡、振动盘、漏吹误吹、涡流/线扫/频闪光源——是"设备+软件"一体化生意。
- **AI做法**：独立**AITOOLS标注训练工具**（完整版才能训练，简易版仅标图）；支持**目标检测（训练尺寸512/320，类YOLO）、语义分割、分类**；本机GPU训练（提示batchsize/显存）；训练图与裁剪图命名必须一致；检测结果在主软件里以"AI模板/教导"方式挂接，可用"深度学习标签最小值"调置信度（www.sjx99.com/nd.jsp?id=30&fromMid=385）。
- **形态**：工控机exe+自研IO控制卡+相机SDK集成，免费软件升级+远程协助，"错误随发随改"，无公开定价（低价走量型）。

## 五、对 LW Vision 的AI功能建议

1. **零基础客户自标自训：可行且是国产竞品共识**——三家的共同范式是"分类/检测二选一 + 预训练迁移学习"，用户只需框图/选OK图。建议流程器内做**一体化AI节点**（标图→训练→推理在同一工程内，避免视觉芯"双软件+命名一致"的断链坑）。
2. **小样本优先有监督分类/检测，无监督做兜底**：工业现场有NG图时YOLO类检测+迁移学习最直观；**纯OK图场景上PaDiM/PatchCore类无监督异常检测**（军哥已验证该路线热度，MVTec同类软件也主打"无需标注"）。建议两者都做成节点：有监督主攻、无监督兜底。
3. **ONNX Runtime落地路径成熟**：训练侧用Python（PyTorch/anomalib/Ultralytics）离线或内嵌训练导出ONNX；C++端用 ONNX Runtime C API（CPU EP为底线，CUDA/TensorRT EP可选）封装成"AI推理"节点，输入输出对齐OpenCV Mat（NHWC/NCHW转换+letterbox预处理），参考DLCV"训练平台+推理SDK分离"的架构和OpenIVS（github.com/dl-cv/OpenIVS）的相机-推理-PLC接线式框架。**避免的坑**：不要绑定单一GPU生态（DLCV强制N卡CUDA12.6）；模型加密/授权要用加密狗或模型混淆（三家均在意）。
