- **git 规范**：小步提交，功能分支，定期 push 远端
- **文档同步**：每阶段更新对应文档，不留"三个盘符三个故事"的历史问题
- **范围控制**：一次只推一个阶段，做完验收再进下一阶段

## 风险与对策

| 风险 | 对策 |
|------|------|
| 移动硬盘是唯一副本 | 尽快建远端私有仓库（Gitee/GitHub） |
| 无硬件开发，真机适配可能返工 | 虚拟相机/模拟PLC先行，驱动接口保持 ICameraDriver/IPLCDriver 抽象不变 |
| 范围大（平台+AI+专项），易烂尾 | 严格按阶段推进，每阶段有明确验收标准 |
| AI 训练依赖 Python 环境 | 训练侧独立打包（训练机可选），部署机只带 ONNX Runtime 推理 |
