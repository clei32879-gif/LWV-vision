## 第一章 快速上手（10 分钟跑通第一个检测）

### 1.1 启动与登录

1. 双击桌面 `LW Vision` 图标（或安装目录中的 LWVision.exe）
2. 登录对话框：默认管理员密码为空，直接点【登录】
3. 主界面五块区域：
   - **左**：工具箱（90 个工具，支持顶部搜索框按名称/功能过滤）
   - **中左**：流程编辑器（节点图，工具在这里编排）
   - **中右**：图像显示区（相机画面/检测结果叠加）
   - **下**：检测项目表 + 良率统计
   - **底状态栏**：鼠标像素坐标 / 授权状态 / 用户 / OK-NG 计数 / 良率

### 1.2 第一次检测（虚拟相机，无硬件也能学）

1. 菜单【相机】→【使用虚拟相机】（自动回放测试图库）
2. 从左侧工具箱双击 **采集图像** → 流程出现节点并自动弹属性框
3. 图像来源选"从相机采集"，点【确定】
4. 双击添加 **阈值分割**：参数里选 OTSU 自动阈值，确定
5. 按 **F5**（执行程序）→ 图像区显示二值化结果，状态栏报"执行完成"
6. 按 **Ctrl+S** 保存工程（.vipj 文件）

> 就这么简单。任何工具：**双击节点 → 改参数 → 看预览 → 确定**。属性框里改任何参数都会自动试执行预览（0.3 秒防抖）。

### 1.3 常用快捷键

| 快捷键 | 功能 |
|---|---|
| F5 / F6 / F7 | 单次执行 / 连续运行 / 停止 |
| Ctrl+N/O/S | 新建 / 打开 / 保存工程 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做（流程编辑操作） |
| Ctrl++ / Ctrl+- | 图像放大 / 缩小 |
| Delete | 删除选中的流程节点 |
| 双击节点 | 打开属性编辑 |

## 第二章 工具箱详解（90 个工具按类使用）

> 每个工具都有中文悬浮说明（悬停在工具箱条目上）。此处按"什么时候用哪个"组织。

### 2.1 取图类（流程第一步）

| 工具 | 用法 |
|---|---|
| **采集图像** | 图像来源三选一：相机采集 / 单文件 / 目录图像列表（自动换图用于测试）。相机名留空=主相机；填 CCD1~8 别名=多相机工位 |
| **切换图像** | 多路图像源选择：按索引或按条件匹配（值来自上游工具输出）从 4 个命名槽选一张写为当前图像 |
| **更新画面** | 把当前图写入指定显示格位（多画面布局时用） |

**相机怎么连**：菜单【相机】→【相机管理 (CCD1~8)】→ 每行填相机 IP →【连接】。连接后可点【参数】在线调曝光/增益/分辨率/触发模式/像素格式（线阵相机额外有行频）。**工位不用就取消"启用"勾选**——它断开且不参与检测。

### 2.2 定位类（几乎所有流程的第二步：先定位再检测）

| 工具 | 什么时候用 |
|---|---|
| **快速找圆** | 工件是圆的（螺钉头/螺母/瓶盖），EdgeDrawing 整图搜圆+Hough 回退，**最推荐的首位定位工具** |
| **形状匹配** | 工件有独特轮廓（L形/异形），支持角度+缩放搜索 |
| **模板匹配** | 灰度纹理定位（含角度/缩放），适合印刷图案 |
| **灰度匹配** | 同模板匹配，金字塔加速，多目标 |
| **轮廓匹配 / 轮廓对比** | 轮廓级匹配 / 一致性比对 |
| **位置补正** | 定位后建立坐标系 → **后续所有工具勾"跟随位置补正"自动跟随工件偏移旋转**（这是 CKVision 流程的灵魂） |
| **结束补正** | 检测组做完后恢复原坐标系（与位置补正配对） |
| **坐标系统 / 坐标校准 / 手眼标定** | 坐标系定义 / 像素-机械坐标映射 / 机器人引导 |

**标准流程骨架**：
```
采集图像 → 图像滤波 → 快速找圆 → 位置补正 → [检测组工具们] → 结束补正 → 计算/判定 → 显示
```
（菜单【文件】→【从模板新建】可一键生成完整骨架，含筛选机/贴标/计数/木业四套模板）

### 2.3 检测识别类（核心工作量区）

| 工具 | 典型场景 | 关键参数提示 |
|---|---|---|
| **BLOB 分析** | 目标计数、缺件检查 | 二值化后按连通域统计；ROI 可选菱形/圆形 |
| **边缘检测** | 找直边位置 | 梯度阈值找不到边时先降"滤波半宽" |
| **检测间距** | 齿距/牙距/相邻间隙 | 沿扫描线全部边缘两两间距 |
| **卡尺测量** | 高精度尺寸（亚像素） | 旋转卡尺，边缘对间距 |
| **检测宽窄** | 料宽/缺料 | 二值化后逐行/列测宽 |
| **检测圆形 / 检测直线** | 亚像素圆/线拟合 | 沿圆周/旋转ROI多卡尺，输出rms |
| **检测顶点** | 角点位置 | 水平×垂直梯度乘积 |
| **边缘凹陷** | 缺件/崩边/缺口 | 扫描取边拟合基线，凹陷深度+段数判定 |
| **像素统计** | 亮度分布/白像素占比 | ROI 灰度统计+阈值区间判定 |
| **亮度检测** | 曝光异常检查 | ROI 均值/方差上下限 |
| **图像对比** | 有无检测（与标准图比） | 与模板差分统计缺陷面积 |
| **螺纹检测** | 螺纹专项（缺牙/烂牙/毛刺/斜牙） | 极坐标展开，牙数/间距自动分析 |
| **颜色识别** | 色差/色块有无 | RGB/HSV/LAB 三色彩空间 |
| **条码识别** | 一维码（Code128/39/EAN/ITF…） | 默认 zxing 引擎；难样本勾"深度识别" |
| **二维码识别 / DM码** | QR / DataMatrix | 位置+文本输出 |
| **字符识别 OCR** | 印刷体/喷码 | 先教导（模式1）再识别（模式0）；charType 可过滤数字/字母 |
| **斑点分类** | 缺陷形状分类 | 按面积/圆度/长宽比/孔数过滤 |

### 2.4 几何测量类

点到点距离、角度测量、点到线、线到线、圆到线、圆到圆、两线交点、延伸点、旋转点——全部支持 `$(工具名.键)` 引用上游输出。例：点到线距离工具的"点X"填 `$(快速找圆.centerX)`。

### 2.5 图像处理类

图像滤波（均值/中值/高斯/双边）、阈值分割（固定/OTSU/自适应）、形态学（腐蚀膨胀开闭梯度顶帽黑帽）、颜色空间转换、图像运算（加减差分与或）、图像合并、裁剪变换（裁剪/镜像/旋转/缩放/平移）、图像补正（亮度均匀化）、图像去畸变、存储图像。

### 2.6 逻辑控制类

| 工具 | 用法 |
|---|---|
| **条件分支** | 表达式判定（如 `$(BLOB.count) < 5`），输出 pass |
| **选择分支 + 分支结束** | 多路方案切换：选择分支按分支号跳转，每路末尾放"分支结束"填自己的分支号 |
| **循环 / 循环结束 / 停止循环** | 重复执行流程段；停止循环支持无条件/流程NG/数据满足三种退出 |
| **执行流程** | 子流程调用（按流程名），实现模块化复用 |
| **脚本节点** | JavaScript：`data["工具.键"]` 读写检测数据、`globals["名"]` 读写全局变量、`log("...")` 打日志，脚本返回 true/false 即 OK/NG |
| **延时** | 等待设备动作（毫秒） |
| **计算变量 / 计算器** | 四则表达式，可引用 3 个数据链接 |
| **设置/获取全局变量** | 跨流程传值 |
| **数据队列** | 缓存最近 N 次结果做统计 |
| **生成/分解/比较文本** | 报文拼装、解析、校验 |
| **数据判断** | 对数据键做上下限判定 |
| **提示对话框 / 播放声音** | 操作工提醒（NG 报警） |
| **系统时间** | 时间戳 / 节拍测量 |

### 2.7 文件通讯类

| 工具 | 用法 |
|---|---|
| **Modbus 读/写数据** | 内置 TCP/RTU 主站，独立连接参数 |
| **PLC 联动** | 筛选机契约一键操作：启动/停止/产量清零/读产量/相机位置/手动拍照/OK-NG剔除/速度/相机使能/剔除位置/良率UPH/轴点动/运行参数 |
| **Modbus 通讯** | 走"PLC连接"里配置好的驱动，slaveId 可覆盖从站地址 |

## 第三章 AI 功能完整使用教程

> 我们的 AI 功能**经过真实数据训练验证**（详见第九章实测记录），分有监督/无监督两条路线。

### 3.1 两条路线怎么选

| 你的情况 | 用哪条 | 工具 |
|---|---|---|
| 有 NG 样本图，缺陷种类明确（开裂/划伤/缺件…） | **有监督分类/检测** | AI 检测 / YOLOv8 检测 |
| 只有 OK 图，"不知道缺陷长什么样但多了就要筛掉" | **无监督异常检测** | anomalib 管线（3.4 节） |
| 缺陷与正常"长得像"（发黑/开裂等纹理型） | 有监督（实测无监督分不开） | AI 检测 |

### 3.2 有监督路线：标注 → 训练 → 部署（全流程）

**第一步：采集与整理图片（30 分钟）**
- 每类至少 20~30 张（良品也要），来源：相机实拍 > 手机翻拍（光照尽量一致）
- 建目录（例）：
```
testdata/cls_dataset/
  train/ 良品/ 开裂/ 发黑/ …
  val/   良品/ 开裂/ 发黑/ …
```
- 训练集/验证集按 8:2 分

**第二步：标注（仅检测任务需要）**
- 菜单【标注】→【缺陷标注工具】：打开图片目录 → 拉框标记缺陷类别 → 一键导出 YOLO 格式 + data.yaml

**第三步：训练（需要 Python 电脑，训练机可选 RTX 3060）**
```
pip install ultralytics
yolo classify train data=testdata/cls_dataset model=yolov8n-cls.pt epochs=50 imgsz=224
# 检测任务:
yolo detect train data=你的data.yaml model=yolov8n.pt epochs=100
```
训练完成后权重在 `runs/classify/train/weights/best.pt`。

**第四步：导出 ONNX（关键一步）**
```
yolo export model=runs/classify/train/weights/best.pt format=onnx imgsz=224
```
得到 `best.onnx`。

**第五步：部署到视觉软件**
1. 把 `best.onnx` 拷到软件目录 `models/` 下（改名如 `缺陷分类.onnx`）
2. 分类模型需在模型旁放 `classes.txt`（一行一个类别名，顺序=训练时目录序）
3. 流程里添加 **AI 检测** 工具：
   - 模型文件：`models/缺陷分类.onnx`
   - 置信度阈值：0.5 起调（漏检多→调低；误报多→调高）
   - **良品类别**：填良品类名（如"良品"），Top1 是良品→OK，否则 NG
   - **检出即 NG**：勾上后"检出任何目标=NG"（缺陷检测模式）

**第六步：AI 工具判定参数（商用级）**
| 参数 | 说明 |
|---|---|
| targetClasses 目标类别 | 逗号分隔，只判这些类（如只判"开裂,发黑"，忽略"良品"） |
| minCount / maxCount | 数量区间判定：**漏检和多检都 NG**（如"必须恰好 1 个缺陷"） |
| confThreshold | 置信度门槛 |
| inferenceMs / device | 输出耗时与设备（CPU/DirectML），调试用 |

### 3.3 AI 训练常见问题

| 问题 | 解法 |
|---|---|
| 误报多 | 置信度阈值调高；增加良品样本量；检查光照一致性 |
| 漏检多 | 阈值调低；增加该类 NG 样本；图像分辨率不足时提高 imgsz |
| 类别混淆 | 两类样本均衡；分类任务用更大模型（yolov8s-cls）|
| CPU 推理慢 | 系统设置→AI 推理设备→自动（有任意 DX12 显卡自动走 DirectML GPU）|
| "AI模块未授权" | 帮助→关于→导入授权文件 |

### 3.4 无监督路线：只喂 OK 图（anomalib）

**适用前提**（实测总结，务必阅读）：
- ✅ 缺陷是划痕/污点/异物/气泡（与正常纹理可分）
- ✅ 产线固定工位+固定光源拍摄，OK 图 50 张以上
- ❌ 缺陷与正常"长得像"（开裂/发黑类）→ 请走有监督
- ❌ 周期性纹理（螺纹）→ 请用螺纹检测传统工具

**操作**（任一装 Python 的电脑执行一次）：
```
pip install anomalib onnxruntime opencv-python
python tools/train_anomalib.py --model Patchcore --align --data <OK图目录>
```
产物 `models/anomalib_wood式目录/weights/onnx/model.onnx` + metadata.json（含自动算好的判定阈值），拷到软件 models/ 即可用 AI 检测工具加载。

## 第四章 常见物料检测项目实操手册

### 4.1 螺钉/螺母筛选机（旗舰场景，8 工位）

**流程模板**：文件→从模板新建→筛选机模板（18 步骨架自动生成）

**典型配置**：
1. 每工位一台相机（相机管理 CCD1~8 分别连接），或共享相机分时拍照
2. 每工位流程：`采集(相机N) → 滤波 → 快速找圆 → 位置补正 → [尺寸/螺纹/BLOB检测组] → 结束补正 → 数据判断 → PLC联动(写结果)`
3. **与 PLC 联动**（信捷 XD5 契约已内置）：
   - 启停：PLC联动工具"启动设备/停止设备"
   - 拍照触发：PLC M121~135 或连续模式软件自触发
   - 结果剔除：检测 NG 后调"手动 NG 剔除"（或 PLC 自动按剔除位置吹气）
   - 产量/良率/UPH：读产量统计 + 读良率与UPH
   - **料仓缺料报警**：PLC HD6 延时参数，软件"写运行参数"可在线调
4. **多相机但只用部分工位**：相机管理里取消不用的"启用"勾选
5. 调试技巧：模拟器先行（设置→PLC模拟器，内置契约地址表），不接真 PLC 就能联调整套流程

### 4.2 视觉贴标机（定位引导）

模板：贴标模板。核心链路：
```
采集 → 形状匹配定位 → 位置补正 → 计算变量(贴标偏移=目标位置-实测位置) → PLC/串口发给贴标机构
```
要点：匹配阈值放宽（0.6）保证抓到目标；偏移量经 CalculateVariable 计算 `$(形状匹配.x)-标准X`。

### 4.3 视觉计数（点料/数量检查）

模板：计数模板。链路：`采集 → 阈值 → 形态学(开运算去噪) → BLOB分析 → 数据判断(count在[min,max]内?)`
要点：相互粘连的目标用形态学腐蚀分离；计数区间在数据判断里配置，漏检多检都 NG。

### 4.4 木业/板材表面检测（AI 路线）

1. 产线固定工位拍 50+ 张 OK 板材图
2. 第三章 3.4 无监督训练一条命令出模型
3. 检测流程：`采集 → AI检测(载入wood模型) → PLC联动剔除`
4. 参考数据集（我们已验证过的下载源）：Zenodo 15679291 木材涂层缺陷 335 张

### 4.5 印刷/喷码检查（OCR + 二维码）

链路：`采集 → 裁剪变换(字符区) → OCR(先教导) → 比较文本(与期望一致?)`；二维码读内容后用比较文本做防错校验。

### 4.6 尺寸全检（卡尺 + 公差判定）

链路：`采集 → 快速找圆 → 位置补正 → 卡尺测量(多处尺寸) → 数据判断(每处上下限) → 数据显示`
要点：亚像素精度 0.1px 级；所有卡尺勾"跟随位置补正"。

## 第六章 故障排查速查

| 现象 | 处理 |
|---|---|
| 找不到相机 | 相机管理里 IP 是否同网段；网线/指示灯；JAI 过滤驱动（丢帧终极方案见部署指南）|
| 找不到边 | 梯度阈值降；滤波半宽降为 1 |
| AI 报"模型加载失败" | models/ 下 onnx 存在；System32 里没有旧版 onnxruntime.dll |
| 连续运行越跑越慢 | 检查 SaveImage 目录写满；日志级别调为"错误" |
