## 1. 亚像素边缘/找线/找圆：OpenCV contrib `EdgeDrawing` ⭐直接可用

- `cv::ximgproc::EdgeDrawing`（ED/EDPF/EDLines/EDCircles），OpenCV 4.5.2+ 内置于 contrib 的 ximgproc 模块
- **许可证 Apache 2.0**（OpenCV）+ 原版 ED_Lib 为 MIT —— 均可商用
- 无参数（EDPF）、实时、亚像素精度，输出线段与圆，是替代 Hough 的现代方案
- 1280×720 找圆约 10~20ms
- **行动**：我们捆绑的 OpenCV 5.0.0 只编译了 core/imgproc/imgcodecs/objdetect/features/flann/geometry，**需重新编译 OpenCV 并加入 opencv_contrib 的 ximgproc 模块**（阶段2 第一项工作）
- 来源：[OpenCV EdgeDrawing 文档](https://docs.opencv.org/4.6.0/d1/d1c/classcv_1_1ximgproc_1_1EdgeDrawing.html)、[CihanTopal/ED_Lib](https://github.com/CihanTopal/ED_Lib)、[opencv_contrib ximgproc samples](https://github.com/opencv/opencv_contrib/tree/master/modules/ximgproc/samples)

## 2. 无监督异常检测：anomalib 导出 ONNX + ONNX Runtime C++ 推理 ⭐路线确认

- anomalib（Intel 开源）原生支持 PaDiM/PatchCore 等模型导出 **ONNX/OpenVINO**，C++ 端 ONNX Runtime 可推理
- **PaDiM 更轻**适合工控机边缘部署；PatchCore 精度更高但推理重（memory bank + coreset）
- **最大的坑**：导出 ONNX 后，C++ 侧必须复刻 Python 侧的预处理（resize/归一化）与后处理（异常图平滑/分数归一化），否则分数对不上 —— 已有多起 C#/LabVIEW 部署翻车案例（GitHub discussion #3644）
- PatchCore ONNX 输出多张量（异常图+分数），解析时要对齐
- **行动**：阶段4 无监督节点按"PaDiM 优先"实施；推理节点带预处理/后处理配置元数据
- 来源：[anomalib 部署文档](https://anomalib.readthedocs.io/en/stable/markdown/guides/reference/deploy/)、[PatchCore ONNX 分数对齐讨论](https://github.com/open-edge-platform/anomalib/discussions/3644)、[Intel 异常检测教程](https://www.intel.cn/content/www/cn/zh/developer/articles/training/defect-detection-with-anomalib.html)

## 3. 螺纹检测算法：标准管线已确认（无现成开源轮子，自研可控）

业界通行四步管线（与我们的设计一致）：
1. 找圆定位螺丝中心（EdgeDrawing/Hough）
2. **`cv::warpPolar` 极坐标展开**——把环形螺纹区展开成矩形条带
3. 条带按角度投影 → 周期性峰值 = 牙数
4. 峰值间距/幅值分析 → 缺牙/烂牙/毛刺/斜牙判定

参考资料：
- [OpenCV 极坐标变换与逆变换教程（中文）](https://www.cnblogs.com/luohenyueji/p/16970212.html)
- [专利 CN104990511A：螺纹缺牙/烂牙/异物/毛刺检测方法](https://patents.google.com/patent/CN104990511A/zh)（判定维度与我们的需求完全对应）
- [螺纹视觉测量论文（Measurement 期刊）](http://ui.adsabs.harvard.edu/abs/2017Meas..100...36G/abstract)
- 深度学习路线参考：[YOLOv11 螺纹与孔检测](https://github.com/Qunmasj-Vision-Studio/Gear-screw-threads-and-holes140)、[金属螺丝表面微缺陷检测（Sensors）](https://www.mdpi.com/1424-8220/18/11/3709)

**行动**：阶段3 螺纹检测按此管线自研（我们已有 testdata 合成螺纹图库做回归）。

- **行动**：阶段3/4 开始时下载 MVTec AD（螺丝类）+ M2 数据集，作为真实样本补充合成图库
