# LW Vision 零维视界

基于深度学习与传统视觉算法融合的通用工业机器视觉检测平台。面向工业自动化产线的质检、测量、定位与分拣场景。

92 个检测工具 | AI 双路线（YOLOv8 有监督 / anomalib 无监督）| 8 相机工位 | PLC 联动（信捷契约）| GPU 加速
