========================================================
LW Vision — 使用说明
========================================================

一、启动软件
  双击文件夹里的 LWVision.exe 即可启动。
  启动后默认以"管理员"身份进入（功能全开），左下角显示"用户: 管理员"。

二、用户与权限（可选）
  软件分三级权限：操作员 / 技术员 / 管理员。
  点工具栏"用户"按钮（或菜单里的"切换用户"）可选角色登录。
  初始状态各角色密码为空，直接点登录即可，无需输入密码。
  如需限制他人改动流程，可给对应角色设置密码（登录框里点"修改密码"）。

三、连接相机
  菜单 → 相机(C)：
  - "扫描相机"：扫描当前可用的相机设备。
  - "打开/关闭相机"：打开或关闭相机，画面显示在中间大图区。
  - "使用虚拟相机"：无相机或演示时，切换到虚拟相机。
  虚拟相机可回放图片：把测试图（.png）放进本目录下的
  testdata\virtual_camera\ 文件夹，再"打开相机"即可看到回放画面。
  （本发布包未内置度申相机驱动；如需真机连接，用带 DVP2 SDK 的版本。）

四、AI 教导向导（现场教导缺陷检测 —— 核心功能）
  工位数默认 8 路 CCD（CCD1～CCD8），对应真机 8 个相机/工位。
  如需改相机数量或给工位改名：菜单 → 设置(S) → 系统设置，里面的
  "相机/工位数量"与"工位名称"(逗号分隔) 改完后重启软件生效。
  操作流（以某一个工位为例，各工位各自独立）：
  1. 菜单 → AI(I) → 教导向导(多工位AI缺陷检测)…，打开向导。
  2. 顶部选工位（每个工位独立训练一个模型，样本/模型按工位名分目录存放）。
  3. 相机、光源固定调好后不再动；在"实时画面"里摆好工件。
  4. 勾选"OK 良品"，点【抓取此帧】抓良品图；
     再勾选"NG 缺陷"，点【抓取此帧】抓缺陷图。
     抓到的图显示在右侧列表，可"标记选中样本 / 删除选中"改标。
  5. 建议每类（OK、NG）各抓 8 张以上，多角度、多位置摆放，越多越准。
  6. 点【开始训练】：软件自动 80/20 切分并训练（CPU 约 3-10 分钟，
     样本越多越久），完成后提示模型保存位置。
  7. 训练完成点【进入检测模式】：画面实时叠加 ✅OK / ❌NG 大字判定。

  注意：
  - 教导"训练"需要本机装 Python + ultralytics（pip install ultralytics）。
    工控机没装时，可在开发电脑训练，再把生成的 .onnx 模型拷到工控机
    models\ 目录（文件名 = 工位名.onnx），即可直接检测。
  - 只做"检测"不需要 Python：模型已存在即可直接点【进入检测模式】。

五、缺陷标注工具（补充训练数据，进阶）
  菜单 → 标注(A) → 缺陷标注工具…，对图片框选标记缺陷并导出，
  用于 YOLO 检测模型训练（详见项目文档 docs\ 目录）。

六、发布包使用条件
  - Windows 10 / 11 64 位操作系统。
  - 本包已自带 Qt、OpenCV、ONNX Runtime 等运行库，一般无需额外安装。
  - 若报缺少 DLL，请把【整个文件夹】一起拷贝使用，不要只拷单个 exe。

七、常见问题
  Q: 双击没反应 / 报缺少 DLL？
  A: 请确认拷贝的是整个文件夹，不是只拷 LWVision.exe 一个文件。
  Q: 画面是黑的？
  A: 点菜单"相机 → 打开/关闭相机"打开相机；或用虚拟相机，并把测试图
     放进 testdata\virtual_camera\ 再打开相机。
  Q: 训练没反应 / 提示没装 Python？
  A: 教导训练需 Python + ultralytics；只做检测不需要 Python。
